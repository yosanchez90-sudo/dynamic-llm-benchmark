Benchmark contamination---the presence of evaluation data in a large language model's (LLM) training corpus---inflates scores on static test suites. This work presents DyMuT (Dynamic Mutation-based Testing), a benchmark for LLM unit-test generation, and tests whether it resists this inflation better than a state-of-the-art static alternative. Six hypotheses were pre-specified for five research questions. The Holm-Bonferroni procedure was used for correcting p-values. Sixty templates, fifteen in each of four cyclomatic-complexity tiers, generate fresh, seeded instances at evaluation time, scored by a seven-operator mutation-testing suite. Nine models were evaluated on DyMuT and on a decontaminated static baseline (ULT). Then an open-source model was fine-tuned on ULT's ground truth to test how each benchmark responds to contamination. The fine-tuned model gained \HTwoSeenGain{} points on the static split it was trained on, but only \HTwoLOneLThreeGain{} points on its untrained DyMuT control, and \HTwoLFourGain{} at complexity-matched tiers. DyMuT therefore rejects the inflation the static benchmark absorbs, supporting dynamic, template-based generation as a practical way to evaluate LLM test generation without contamination inflating the result.
