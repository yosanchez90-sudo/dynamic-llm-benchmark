Benchmark contamination: the presence of evaluation data in a large language model's (LLM) training corpus, inflates scores on static test suites. This work presents DyMuT (Dynamic Mutation-based Testing), a benchmark for LLM unit-test generation, and tests whether it resists this inflation better than a state-of-the-art static alternative. Six hypotheses were pre-specified for five research questions. The Holm-Bonferroni procedure was used for correcting p-values. Sixty templates were constructed each with four cyclomatic-complexity tiers that generate fresh, seeded instances at evaluation time, scored by a seven-operator mutation-testing suite. Nine models were evaluated on DyMuT and on a decontaminated static baseline (ULT). Then an open-source model was fine-tuned on ULT's ground truth to test how each benchmark responds to contamination. The fine-tuned model improved its performance on the static split while on DyMuT did not, showing that DyMuT rejects the contamination that the static benchmark absorbs, supporting dynamic, template-based generation as a practical way to evaluate LLM test generation without contamination inflating the result.
