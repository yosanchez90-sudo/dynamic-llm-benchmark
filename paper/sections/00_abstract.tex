Benchmark contamination: the presence of evaluation data in a large language model's (LLM) training corpus, inflates reported scores on static test suites. This work evaluates whether a dynamic, template-based benchmark for LLM unit-test generation resists this inflation more effectively than a state-of-the-art static alternative. Sixty parameterised templates spanning four cyclomatic-complexity tiers generate fresh, seeded instances at evaluation time, scored by a seven-operator mutation-testing suite rather than fixed tests. Nine models were evaluated against the dynamic benchmark and a decontaminated static baseline (ULT), and a small open-source model was fine-tuned on that baseline's ground truth to probe contamination sensitivity. The fine-tuned model gained \HTwoSeenGain{} percentage points on the memorised static split against an \HTwoLOneLThreeGain{}-point generic improvement control, while its dynamic-benchmark score moved by exactly zero, the clearest evidence that it rejects contamination the static one absorbs. Six hypotheses were pre-specified and evaluated under Holm-Bonferroni correction and p-values are applied; the causal contamination-resistance evidence remains. One pre-specified prediction was contradicted: the dynamic benchmark tracked external code-generation ability more closely than the static benchmark. One comparison was not distinguishable from no effect, and one stability threshold was not met. The findings support dynamic, template-based generation as a practical, contamination-resistant evaluation strategy for LLM test-generation research.
