## Glossary

| Group | Symbol / term | Means | Watch out for |
|---|---|---|---|
| Governance | approved hypothesis set | The six hypotheses (H1-H6) submitted to and approved by the supervisor. H1 carries two tests; H5 covers the whole of RQ4. | This is the ONLY set the paper reports. A later expanded draft (H4a/H4b, separate RQ4.2-4.4 hypotheses) was never submitted and creates no obligation. |
| Counts | K | Attempts per problem, Pass@K style. Always 1 here, so Mut@K = Mut@1. | Do not confuse with m. |
| Counts | m | Instances generated per template (m=5). Prose-only symbol. | Was previously also written as 'K' - the collision fixed in the notation pass. |
| Counts | N | Instantiation SCOPE - which independent re-generations of the benchmark an analysis uses. N=4 headline; N=5 approved target. | A property of the analysis plan, not a count of anything measured. |
| Counts | n_models | How many MODELS enter one comparison or correlation. | This is what 'n' means in Comparison A/B, RQ5 and the stability pairs. |
| Counts | n_problems / n_total | How many PROBLEM ROWS are in a group. | This is what 'n' means in Comparison C (112, 288, 400...). |
| Counts | n_defined | Rows where mutation_score is not None - i.e. rows that passed the baseline gate. | Always a subset of n_problems. Below 20 the cell is flagged 'thin'. |
| Counts | n_instantiations | Per-model count of instantiations contributing to that model's own StableMut@K. | A third distinct meaning of n - not the project-wide N. |
| Aggregation | pooled | One average over ALL rows in scope at once - pooled Mut@K = the mean over every baseline-passing row across L1-L4 together. | A mean over ROWS, not of the four tier means, so tiers with more rows weigh more. 'Dynamic-pooled vs ULT' compares a mixed-difficulty benchmark against a hard-only one. |
| Aggregation | tier-matched | Restricting the dynamic side to L4 (CC>=8) so it sits in the same complexity band as ULT. | Comparison A does this; RQ5's pre-registered primary does not. |
| Aggregation | mean-of-means | Averaging per-group averages rather than raw rows. | Used deliberately in exactly one place - StableMut@K over instantiations. |
| Units | pp | Percentage POINTS - the arithmetic difference between two percentages. | 0.9% rising to 100% is +99.1pp, not '+11,000%'. |
| Units | CI | Confidence interval - always a 95% bootstrap CI here. | If a CI excludes zero the effect is distinguishable from no-effect. Effect sizes and CIs are primary; p-values supporting. |
| Metrics | exec_rate (Exec@K) | Did the generated test file import and get collected by pytest? | A very low bar - a suite can execute and still assert wrong values. |
| Metrics | baseline_pass_rate | Fraction of rows whose suite PASSES against the original, correct function. | The precondition for mutation scoring. 2.0% (Qwen 1.5B on ULT) to 96.3% (GPT-5 on Dynamic-L4). |
| Metrics | Mut@K (conditional) | Killed / scored mutants, averaged ONLY over baseline-passing rows. The pre-registered primary. | Each model is averaged over a different, self-selected subset of problems. |
| Metrics | coverage_adjusted | Mut@K x baseline_pass_rate - proven equal to the zero-filled unconditional mean. | Matches the ULT paper's PROSE; the paper's own CODE matches this project's conditional primary instead. |
| Metrics | StableMut@K | Mean Mut@K across instantiations, with its SD. | The deliberate mean-of-means exception - the SD is the point. |
| Metrics | verbatim-match rate | Fraction of post-fine-tune completions byte-identical to their training target. | 112/112 on seen-ULT - direct memorisation evidence. |
| Populations | Dynamic-pooled | All four tiers L1-L4 pooled. RQ5's primary. | NOT CC-comparable with ULT. Always write 'Dynamic-pooled', never bare 'Dynamic'. |
| Populations | Dynamic-L4 | The CC>=8 slice matched to ULT's band. Comparison A. | CC-fair, but floor-limited for the smaller Qwen models. |
| Populations | Dynamic-L1-L3 | The non-CC-matched headroom control in Comparison C. | Deliberately asymmetric and labelled as such. |
| Populations | core_400 | The fixed CC-stratified 400-problem subsample of ULT (and PLT) every model is evaluated on. | Fixed so cross-model comparisons are paired. |
| Populations | seen-ULT / unseen-ULT | Within core_400: 112 problems with a repair-verified training pair vs 288 without. | Unseen is NOT a random hold-out - it is defined by unrepairability, so it is a harder, messier population. |
| Populations | canonical vs cross-family | Canonical = the 9-model panel. Cross-family = 4 extra open-source models added only to break the all-Qwen size confound in RQ5. | Cross-family models never enter Comparison A/B or StableMut@K - enforced by a filter with a regression test. |
| Statistics | Pearson r | Linear correlation on raw score values. | Highly outlier-sensitive. |
| Statistics | Spearman rho | Pearson computed on ranks - monotone relationship. | The approved H3 and H6 both name it. |
| Statistics | Kendall tau | (concordant - discordant) / total pairs. Rank agreement. | At n=3 only four values are possible and the best possible p is 0.167. |
| Statistics | Wilcoxon signed-rank | Non-parametric paired test - here paired per model across two benchmarks. | Its rank-biserial effect_r can disagree in DIRECTION with a raw column-mean comparison, and only the test statistic is what H1 measures. |
| Statistics | effect_r (rank-biserial) | Paired effect size from the Wilcoxon test. Negative = Dynamic-L4 favoured. | Resistant to a couple of large-magnitude outliers. |
| Statistics | DiD | (POST - PRE) on the treated benchmark minus (POST - PRE) on a control benchmark. | The '2x3' is PRE/POST x {ULT, PLT, Dynamic}. Reports CIs, not p-values, by design. |
| Statistics | Permutation p | p-value from shuffling one side's labels many times. | Used because n_models is small. |
| Statistics | Holm-Bonferroni | Correction for multiple tests within one RQ family. | RQ1's family now holds TWO p-values (H1 Test 1 and Test 2), not one. RQ4 and RQ5 have their own families. |
| Statistics | Fisher z-test | Test for whether two correlations differ significantly. | NOT required by the approved H6 - it appeared only in the unapproved expanded draft. |
| Quality flags | thin cell | A model x benchmark cell with n_defined < 20. | Its Mut@K is a shaky point estimate however respectable the number looks. |
| Quality flags | floor effect | The model cannot clear a gate at all, so the metric sits at its minimum before and after any intervention. | Qwen 1.5B has 0 defined rows at Dynamic-L4. |
| Quality flags | noise floor | When the gap between two models is smaller than their own between-instantiation SDs. | Five adjacent models share a pooled spread of 0.005 (corrected 2026-08-12 from a stale 'six... 0.007', which predated Gemini Pro Preview's Dynamic-L4 crawl completing 2026-08-11) - they cannot be reliably rank-ordered. |
